# Linear and Polynomial Regression

## Features

- Linear Regression using Boston Housing Dataset
- Polynomial Regression for non-linear prediction
- Data visualization using Matplotlib
- Model training and prediction
- Comparison of actual and predicted values

## Concept

Linear Regression predicts the target variable using a straight-line relationship between input and output variables.

Polynomial Regression extends Linear Regression by introducing polynomial features to capture non-linear relationships in the data.

## Dataset

### Linear Regression
Boston Housing Dataset

Source:
https://raw.githubusercontent.com/selva86/datasets/master/BostonHousing.csv

### Polynomial Regression
Auto MPG Dataset (Vehicle Fuel Efficiency Prediction)
